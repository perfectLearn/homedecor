PERFECT HOME - Furniture E-Commerce Website

Open index.html in a browser or use VS Code Live Server.

Pages:
1. index.html - Home
2. products.html - Product listing/search/filter
3. product-details.html - Product details
4. cart.html - Cart + checkout + order placement
5. account.html - Sign up / Sign in / account

Data is stored in browser localStorage. This is a front-end practice/demo website; passwords and orders are stored locally and are NOT suitable for production.

Internet is required for the furniture images and Google font because this version uses remote image URLs. You can replace image URLs in js/products.js with local images later.
